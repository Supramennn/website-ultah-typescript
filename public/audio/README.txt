Taruh file lagu di folder ini, lalu isi music.src pada src/data/config.ts.

Contoh:
  file: public/audio/lagu-kita.mp3
  config: src: "/audio/lagu-kita.mp3"

Tombol musik hanya muncul setelah src diisi.
Musik tidak autoplay karena browser memblokir audio sebelum ada interaksi pengunjung.
Gunakan file MP3 atau M4A dengan ukuran wajar, misalnya di bawah 5 MB.
